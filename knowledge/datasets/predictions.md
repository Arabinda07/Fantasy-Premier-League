# Schema: `predictions.csv`

The baseline points prediction file generated by [model/prediction_engine.py](/computations/predict-points.md). Represents player point expectations before venue and opponent fixture multipliers are applied.

## Core Identification & Probabilities

| Column | Type | Description |
|---|---|---|
| `player_code` | `INTEGER` | Permanent FPL player code. |
| `web_name` | `STRING` | Player standard FPL display name. |
| `team` | `STRING` | Club name (e.g. `'Arsenal'`). |
| `position` | `STRING` | Player position (`'GK'`, `'DEF'`, `'MID'`, `'FWD'`). |
| `now_cost` | `INTEGER` | Price in tenths of millions (e.g. `105` = £10.5M). |
| `p_start` | `FLOAT` | Final projected probability of starting the match. |
| `p_app` | `FLOAT` | Probability of appearing in the match ($P(\text{Start}) + P(\text{Sub})$). |
| `p_60_plus` | `FLOAT` | Probability of playing $\ge 60$ minutes. |

## 11 Component Expected Points Breakdown ($C_1 \dots C_{11}$)

| Column | Component | Description |
|---|---|---|
| `c1_app_1_60` | $C_1$ | Expected appearance points for any appearance ($1.0 \times P(\text{App})$). |
| `c2_app_60_plus` | $C_2$ | Expected additional appearance points for 60+ minutes ($1.0 \times P(60+)$). |
| `c3_saves` | $C_3$ | Expected goalkeeper save points ($\frac{1}{3} \times \text{saves}90 \times P(\text{Start})$ for GK). |
| `c4_yellow_cards` | $C_4$ | Expected yellow card penalty ($-1.0 \times yc90 \times P(\text{App})$). |
| `c5_red_cards` | $C_5$ | Expected red card penalty ($-3.0 \times rc90 \times P(\text{App})$). |
| `c6_bonus` | $C_6$ | Expected FPL bonus points ($\text{bonus}90_{\text{adj}} \times P(\text{Start})$). |
| `c7_assists` | $C_7$ | Expected assist points ($3.0 \times xA90_{\text{adj}} \times \text{active\_ratio}$). |
| `c8_goals` | $C_8$ | Expected goal scoring points ($\text{GoalPts}(\text{POS}) \times xG90_{\text{adj}} \times \text{active\_ratio}$). |
| `c9_clean_sheets` | $C_9$ | Expected clean sheet points ($\text{CleanSheetPts}(\text{POS}) \times P(60+) \times e^{-\lambda}$). |
| `c10_goals_conceded` | $C_{10}$ | Discrete Poisson expectation for $GC \ge 2$ penalty ($\mathbb{E}[\text{Penalty}] \times P(60+)$ for GK/DEF). |
| `c11_defensive_contributions` | $C_{11}$ | Points from tackles, blocks, clearances ($[P(\text{DC}\ge 10) + P(\text{DC}\ge 15)] \times P(60+)$). |

## Total Projected Baseline Points

| Column | Type | Description |
|---|---|---|
| `expected_points` | `FLOAT` | Unadjusted baseline expected points: sum of all 11 scoring components ($\sum_{k=1}^{11} C_k$). |

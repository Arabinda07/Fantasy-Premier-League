# Schema: `gws/merged_gw.csv`

The unified historical dataset combining individual gameweek records for every player across the entire season. Generated by [collector.py](/scrapers/fpl-api-pipeline.md).

## Primary Columns

| Column | Type | Description |
|---|---|---|
| `name` | `STRING` | Player full name (`first_name_second_name`). |
| `element` | `INTEGER` | Player ID corresponding to `id` in [players_raw.csv](/datasets/players-raw.md). |
| `GW` | `INTEGER` | Gameweek number (1 to 38). |
| `minutes` | `INTEGER` | Total minutes played in the fixture. |
| `total_points` | `INTEGER` | Official total FPL points earned in the gameweek. |
| `goals_scored` | `INTEGER` | Goals scored in the fixture. |
| `assists` | `INTEGER` | Assists credited by FPL. |
| `clean_sheets` | `INTEGER` | `1` if 60+ minutes played with 0 goals conceded, `0` otherwise. |
| `goals_conceded` | `INTEGER` | Total goals conceded while the player was on the pitch. |
| `own_goals` | `INTEGER` | Own goals scored. |
| `penalties_saved` | `INTEGER` | Penalties saved by goalkeeper. |
| `penalties_missed` | `INTEGER` | Penalties missed by penalty taker. |
| `yellow_cards` | `INTEGER` | Yellow cards received (`0` or `1`). |
| `red_cards` | `INTEGER` | Red cards received (`0` or `1`). |
| `saves` | `INTEGER` | Total saves made by goalkeeper. |
| `bonus` | `INTEGER` | Bonus points awarded (`0`, `1`, `2`, or `3`). |
| `bps` | `INTEGER` | Raw Bonus Points System score. |
| `influence` | `FLOAT` | FPL ICT Influence metric. |
| `creativity` | `FLOAT` | FPL ICT Creativity metric. |
| `threat` | `FLOAT` | FPL ICT Threat metric. |
| `ict_index` | `FLOAT` | FPL ICT Index overall metric. |
| `value` | `INTEGER` | Player price in tenths at time of gameweek (e.g. `105` = £10.5M). |
| `transfers_balance` | `INTEGER` | Net transfers in minus transfers out for that gameweek. |
| `selected` | `INTEGER` | Total managers owning the player at gameweek deadline. |
| `was_home` | `BOOLEAN` | `True` if home match, `False` if away match. |
| `opponent_team` | `INTEGER` | Opponent team ID (1 to 20), foreign key into [teams.csv](/datasets/teams-and-fixtures.md). |

## Joins & Downstream Dependencies

- Fed into [model/rolling_form.py](/models/fixture-and-form-engine.md) to calculate rolling form rates over 6-gameweek and full-season windows.
- Joined with Understat and FBref match data in [model_dataset.csv](/datasets/model-dataset.md).

# Schema: `fpl_matchday_live_gw*.json`

Structured JSON payload generated by [model/live_sync.py](/computations/sync-live-gameweek.md) and [model/enrich_frontend_data.py](/architecture/end-to-end-data-flow.md) providing live match status, squad points, captaincy, and auto-subs for frontend rendering.

```json

  "season": "2026-27",

  "last_updated": "2026-08-26T19:00:00Z",
  "gameweek_status": "live", // "pre_deadline" | "live" | "finished"
  "summary": {
```

## Field Definitions

* `summary.total_live_points`: Current sum of points for the starting XI including active captaincy multipliers.
* `summary.projected_final_points`: Realized points on finished players plus expected points on remaining fixtures.
* `starting_xi[].provisional_bonus`: Real-time modeled bonus points based on live BPS standings.
* `bench[].auto_sub_status`: Tracks whether a bench player has been subbed on for a starter who recorded 0 minutes.

# Schema: `fixture_predictions.csv` (or `fixture_predictions_gw*.csv`)

The primary decision-making dataset generated by [model/fixture_engine.py](/computations/adjust-fixtures.md). Scales baseline points by upcoming opponent defensive/attacking ratings, venue factors, and short-form blending.

## Player & Fixture Metadata

| Column | Type | Description |
|---|---|---|
| `player_code` | `INTEGER` | Permanent FPL player code. |
| `web_name` | `STRING` | Player display name. |
| `team` | `STRING` | Player's club name (e.g. `'Arsenal'`). |
| `position` | `STRING` | Player position (`'GK'`, `'DEF'`, `'MID'`, `'FWD'`). |
| `now_cost` | `INTEGER` | FPL price in tenths (e.g. `105` = £10.5M). |
| `gw` | `INTEGER` | Target Gameweek number. |
| `fixture_count` | `INTEGER` | Total fixtures for this player in the gameweek (0=Blank, 1=Single, 2=Double). |
| `fixture_opponent` | `STRING` | Opponent name (e.g. `'Aston Villa'`). |
| `fixture_venue` | `STRING` | `'H'` for Home, `'A'` for Away. |
| `fixture_fdr` | `INTEGER` | Official FPL Fixture Difficulty Rating (1 to 5). |
| `fixture_attack_mult` | `FLOAT` | Opponent- and venue-scaled attacking multiplier. |
| `fixture_xgc90` | `FLOAT` | Opponent- and venue-scaled expected goals conceded per 90. |

## Adjusted Component Points ($C_1 \dots C_{11}$) & Final xP

| Column | Component | Description |
|---|---|---|
| `c1_app_1_60` | $C_1$ | Fixture-adjusted appearance points (1-59 mins: $1.0 \times P(\text{App})$). |
| `c2_app_60_plus` | $C_2$ | Fixture-adjusted appearance points (60+ mins: $1.0 \times P(60+)$). |
| `c3_saves` | $C_3$ | Fixture-adjusted goalkeeper save points (scaled by opponent attacking volume). |
| `c4_yellow_cards` | $C_4$ | Expected yellow card penalty ($-1.0 \times yc90 \times P(\text{App})$). |
| `c5_red_cards` | $C_5$ | Expected red card penalty ($-3.0 \times rc90 \times P(\text{App})$). |
| `c6_bonus` | $C_6$ | Attack-volume scaled bonus expectation ($\text{bonus}90 \cdot \text{clamp}(\text{Attack\_Mult}^{0.75}, 0.3, 2.0)$). |
| `c7_assists` | $C_7$ | Venue- and opponent-scaled assist points ($3.0 \times xA90_{\text{adj}} \times \text{Attack\_Mult} \times \text{active\_ratio}$). |
| `c8_goals` | $C_8$ | Venue- and opponent-scaled goal scoring points ($\text{GoalPts} \times xG90_{\text{adj}} \times \text{Attack\_Mult} \times \text{active\_ratio}$). |
| `c9_clean_sheets` | $C_9$ | Opponent-adjusted Poisson clean sheet expectation ($\text{CleanSheetPts} \times P(60+) \times e^{-\text{Fixture\_xGC90}}$). |
| `c10_goals_conceded` | $C_{10}$ | Opponent-adjusted discrete Negative Binomial $GC \ge 2$ penalty evaluated separately over starter duration and substitute cameos. |
| `c11_defensive_contributions` | $C_{11}$ | Pressure-scaled defensive contributions ($[P(\text{DC}\ge 10) + P(\text{DC}\ge 15)] \times P(60+)$). Excluded from standard official FPL scoring by default. |
| `expected_points` | Total | Final fixture-adjusted expected points for the target gameweek ($\sum_{k=1}^{10} C_k$ for official FPL scoring by default, or $\sum_{k=1}^{11} C_k$ with `--include-c11-in-xp`). |
